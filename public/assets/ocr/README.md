# Local OCR assets

Official PaddleOCR.js 0.4.2 module worker, unmodified, from the npm package
`@paddleocr/paddleocr-js`. It includes OpenCV.js, Clipper, js-yaml and ONNX Runtime
Web 1.24.3. The independent `ocr-onnxruntime` npm alias pins matching JSEP assets;
the existing image enhancement/watermark runtime stays at 1.20.1.

PP-OCRv5_mobile_det and PP-OCRv5_mobile_rec ONNX tar archives are unmodified
downloads from the official Paddle model hosting URLs recorded in manifest.json.
Checksums and byte lengths are verified at build time and before browser use.
The joint recognition dictionary supports Simplified/Traditional Chinese,
English and Japanese, without a user-selected recognition language. This does
not imply universal language identification or coverage of every language.

The main-thread adapter follows the pinned SDK's worker transport contract to
avoid importing a duplicate OpenCV/ORT bundle into the page. When updating the
SDK, review the protocol, normalized config, embedded ORT version and rerun real
browser GPU and CPU tests. Cancellation terminates the worker and aborts model
downloads. Automatic mode retries CPU if GPU initialization or inference fails.

Original-resolution images are split into overlapping tiles up to 2048×1536,
with 192px overlap. Detection uses a maximum 1536px edge, recognition crops use
the source pixels, and overlapping boxes are deduplicated. The optional small
text setting upscales smaller images up to 2× for detection. Reading order uses
approximate baselines; complex columns, tables, handwriting and severe blur
still require manual review. 100% preview and region selection are available.

The original multilingual sample `example.webp` is generated by
`node scripts/ocr-example.mjs`. It contains real printable text; no expected text
is fed into OCR. TXT exports contain the edited full text; JSON also retains
original line text, confidence and coordinates in the current rotated image.

Preparation: `node scripts/prepare-ocr.mjs`. Maintenance download:
`node scripts/prepare-ocr.mjs --download`. Neither requires a backend at runtime.
