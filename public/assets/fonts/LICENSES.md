# Bundled fonts

Self-hosted subsets from Google Fonts. All four font families use the SIL Open Font License 1.1. CJK display subsets cover the shipped homepage and tool titles; other characters use system serif fallbacks.

- Inter: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt
- Cormorant Garamond: https://raw.githubusercontent.com/google/fonts/main/ofl/cormorantgaramond/OFL.txt
- Noto Serif SC: https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/OFL.txt
- Noto Serif JP: https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifjp/OFL.txt
