# 晃动图片工坊交付记录

完成日期：2026-10-03。参考 purupurumaker.com 的涂抹、晃动、录制流程，保持项目 DESIGN.md 的暖色画廊界面。

## 已实现

- 默认打开原创焦糖布丁：布丁形变、盘子固定；三种可直接载入继续编辑的动态案例。
- 本地 PNG/JPEG/WebP 上传与拖放，80 MB 上限，静态图片检查、替换确认与读取错误反馈。
- 柔边涂抹、橡皮、强度与大小、16 步撤销重做、全涂、反转、清空。
- 滚轮与双指缩放、拖动平移、视图重置；鼠标与触摸拖动；方向键推动、空格暂停。
- 四种材质、七个精细物理参数、重力方向/强度、三条循环运动路径与关闭状态。
- 真实实时录制，保留拖动动作；GIF 后台线程编码；WebM 和支持浏览器中的原生 MP4；不以 WebM 冒充 MP4。
- 时长、构图、进度、提前停止保存、取消、结果预览与保存链接，资源释放和对话框焦点管理。
- 手机体感的用户主动授权、旋转轴适配及无数据反馈。
- 首页精选和工具集合的动图案例、首屏画框布丁替换，中英日页面、深色主题和减少动态效果支持。

- `node --test tests/wiggle.test.mjs tests/wiggle-recording.test.mjs`：13 项通过。
- 测试涵盖布丁/盘子蒙版、笔刷快照、四种材质持续强力推动下的稳定性、30/120 fps 一致性、三种无限循环动图、格式支持、稳定构图、录制取消和流释放。
- 浏览器实际操作验证：图片替换、涂抹、撤销重做、空蒙版提示、缩放、取消录制、GIF 结果预览、WebM 解码（720×720、约 5 秒）、MP4 解码（720×720、提前停止约 0.3 秒）。

- 首屏画框已显示布丁；首页两处案例图片都正确加载动态 WebP。

## 仍需真实设备验证

手机体感和双指触控的物理设备手感无法由桌面浏览器完整验证。体感只在用户主动点击时请求权限；安全连接和传感器支持由设备决定。

## 资产与复现

布丁及首屏替换使用内置图片生成工具原创生成，方向为「透明底、焦糖布丁、象牙白瓷盘、温暖摄影」。动图由同一套物理引擎生成，未复制参考网站的素材。

`node scripts/generate-wiggle-examples.mjs` 可从 public/assets/wiggle/pudding.webp 重建三种 GIF 和动态 WebP。
